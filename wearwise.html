Wearwise

A full-stack wardrobe planner that uses weather, occasion, inventory state, and constrained automation to produce reliable, traceable outfit plans.

Problem framing

Wearwise treats clothing availability as operational state. A useful recommendation must reflect current conditions, only select available items, update inventory consistently, and leave a readable record of the plan.

Transactional workflow

When a plan is created, the server verifies that every selected item belongs to the authenticated user and is clean. It then stores a dated plan and immutable item snapshot before marking those exact items dirty within one database transaction.

Condition-aware decision support

Current weather and occasion inputs narrow the decision context. Recommendations operate only on clean inventory, while dated plans and a versioned JSON export preserve the state used for each decision.

Bounded AI automation

Structured response schemas, category validation, an allowed-item identifier list, duplicate removal, and minimum-item checks keep model output inside the application's constraints. If a model call fails, deterministic fallbacks preserve a usable cataloging and planning path.

System architecture

The private workflow combines a React and TypeScript client with Express, tRPC, Drizzle ORM, relational storage, and server-side image analysis. A separate static companion demonstrates local catalog filtering, laundry state, weather input, and history export without exposing the authenticated data workflow.

Verification and limits

Type checking, four focused unit tests, and a production build passed during repository review. The tests cover authentication logout and core wardrobe-planning rules; this project is presented as a workflow and data-reliability case study, not as mechanical analysis or a production reliability claim.
