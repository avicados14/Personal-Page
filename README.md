# Avi Aggarwal — Personal Website

A static engineering portfolio for Avi Aggarwal, a Mechanical Engineering student at Colorado School of Mines working across power systems, automation, mechanical design, and technical education.

## Live site

[avicados14.github.io/Personal-Page](https://avicados14.github.io/Personal-Page/)

## Site structure

All deployable files remain in the repository root for straightforward GitHub Pages hosting.

- `index.html` — profile and selected work
- `portfolio.html` — projects, experience, and technical toolkit
- `resume.html` — accessible web resume with scroll reveals
- `passions.html` — technical and personal interests
- `contact.html` — contact details and scheduling embed
- `pid-oven.html`, `xcel-energy.html`, and other detail pages — project and role case studies
- `colors.css` — shared design system and responsive styles
- `site.js` — shared navigation, reveal, and utility interactions
- `Resume.pdf` — current downloadable one-page resume

## Design direction

The interface uses an engineering field-notebook concept: deep navy, blueprint-style geometry, disciplined typography, and a focused professional pink accent. The system includes visible keyboard focus, reduced-motion support, responsive layouts, and print styles for the web resume.

## Deployment

The repository is compatible with GitHub Pages and requires no build step. Pages are served directly from the `main` branch root.
